# Triage Labels

skill 里说的是五个规范 triage 角色；这张表把角色映射到本仓 issue tracker 里实际用的标签串。

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这条 issue |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

skill 提到角色（例如「打上 AFK-ready 的 triage 标签」）时，用右列对应的标签串。
右列可随时改成你实际在用的词。
